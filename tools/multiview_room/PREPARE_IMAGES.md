# 本地多照片与视频素材准备

这是电脑离线原型的素材步骤，当前没有接入 Android 相机或相册。工具只输出 PNG 和 preparation.json，不生成房间、墙长、相机位姿或真北方向；不访问网络、不上传文件、不修改源照片/视频和住宅文件。

安装同目录 requirements.txt 中的依赖后：

```powershell
python prepare_images.py --photos photo1.jpg photo2.jpg photo3.jpg photo4.jpg photo5.jpg photo6.jpg --output runs/photos-001
python prepare_images.py --video room.mp4 --interval 0.5 --output runs/video-001
```

`--output` 必须是新的实验目录。成功返回 0 仅代表至少六张素材已准备，状态是 prepared_images_only；质量不足或输入失败返回 2，并在新目录记录 rejected。已有目录会在写入前拒绝，避免旧结果被误当作本次结果。

默认最多保留 80 张，可设置 6–200；视频最长 180 秒，抽样间隔为 0.2–10 秒。所有图像保留解码后的原分辨率；不同图像尺寸会被拒绝。采用固定镜头与变焦，并为这个尺寸准备真实相机内参和显示坐标下的人工墙角标注，不能复用合成示例的相机参数或墙角坐标。

质量检查采用最长约 640 像素的灰度图 Laplacian 方差阈值 80，以及 160×120 缩略图的相邻 RMSE 小于 3 / 解码像素哈希判重。它们只是筛掉明显模糊、低纹理或相近画面的启发式，不保证视觉重叠、位移视差或几何配准成功，也可能排除可用素材。`--blur-threshold` 允许实验者调整清晰度阈值；放宽阈值不绕过后续重建门槛。

像素解码会丢失原文件的一些 EXIF 信息。后续重建所需内参、镜头/变焦和标注必须单独保存并核对。输出是 local PNG 与质量报告，没有自动推测米制尺寸。
