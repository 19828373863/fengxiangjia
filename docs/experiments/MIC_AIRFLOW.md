# 实验 FXJ-23：麦克风辅助气流比较（#24）

> **结论（当前）：不纳入首版。** 实验需普通 iPhone 实测，**尚未运行**；在达到下述门槛前，App 不申请麦克风权限、不含相关代码（`check_compliance.py` 可扩展为禁止 `NSMicrophoneUsageDescription`）。

## 假设
气流吹过麦克风产生低频湍流噪声（< 200 Hz）。在同一位置、同一姿态下比较 A/B 两种摆法的低频能量，**只做相对比较**（哪种更有风），不估算风速。

## 主要风险
1. **风扇自身噪声误报**：电机/叶片噪声与风噪频段重叠；扇叶通过频率（BPF = 转速 × 叶片数，约 20–80 Hz）及谐波
2. **姿态影响**：麦克风开孔朝向/遮挡、手持晃动显著改变读数
3. **机型差异**：多麦克风、系统降噪（`AVAudioSession` 模式 `.measurement` 可关闭大部分处理）
4. 隐私观感：麦克风权限对“风扇摆放”工具显得突兀

## 方法（待执行）
- 采集：`AVAudioEngine`，`.measurement` 模式，48 kHz，单声道，每次 10 s，手机放在固定支架上，麦克风开孔朝向风扇
- 特征：20–200 Hz 频带 RMS（dB），减去扇叶通过频率 ±3 Hz 的窄带峰；对照组：风扇开但用纸板挡住出风口（只剩噪声）
- 设备：≥ 3 款普通 iPhone（含无 LiDAR 低端机）
- 场景：3 个距离（1/2/3 m）× 2 档 × 3 种姿态（平放/竖立/手持）× 每组 5 次

## 可用门槛（全部满足才考虑纳入）
| 指标 | 门槛 |
|---|---|
| 重复性：同条件 5 次的标准差 | < 2 dB |
| 区分度：有风 vs 挡风对照 | 差值 > 6 dB，且 ≥ 90% 试次方向正确 |
| A/B 排序与风速计参考一致率 | ≥ 85% |
| 姿态变化引起的偏差 | < 区分度的一半 |
| 跨机型排序一致 | 3 款机型均满足上述 |
